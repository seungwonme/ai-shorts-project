# 레퍼런스: 분석 보고서 예시

수업에서 보여 드린 분석 결과입니다. 읽어 보기만 하는 폴더이고, Codex가 이 폴더에 파일을 만들거나 고치지 않습니다.

## 솔직후기-분석

KAIST 공식 쇼츠 「POSTECH 학생들의 KAIST 방문 솔직후기!」(2023-10-19, https://www.youtube.com/shorts/IyGoQWBCanQ)를 `kaist-shorts-analyze`로 분석한 결과입니다.

- `솔직후기-분석/report.html`을 더블클릭하면 브라우저에서 열립니다(인터넷이 없어도 열립니다).
- 같은 폴더의 `frames/`(컷마다 첫 화면), `contact-sheet.jpg`(컷 모음표), `first-frame.png`, `title-crop.png`(제목 잘라낸 그림), `audio-clip.mp3`(소리 12초)를 보고서가 불러옵니다. 폴더째 두어야 합니다.
- `analysis.json`(측정값), `findings.json`(Codex가 그림을 보고 채운 내용)은 보고서의 재료입니다.

내 분석은 `결과/<날짜>-분석-<이름>/` 폴더에 따로 만들어집니다. 이 예시는 모양과 내용을 참고하는 용도입니다.

영상과 화면의 저작권은 KAIST에 있습니다. 공부와 참고용으로만 보시고 다시 올리지 마세요.
