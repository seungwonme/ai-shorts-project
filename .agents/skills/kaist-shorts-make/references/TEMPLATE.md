# KAIST 공식 쇼츠 틀 (행사 쇼츠형)

@KAISTofficial 2023 행사 쇼츠(솔직후기 `IyGoQWBCanQ`, 카포전 현장스케치 `NYiwcEkz4as`, 카포전 농구, 이도현, 축제)가 같은 틀을 쓴다. 2026-11-15에 1080x1920 원본 프레임에서 픽셀로 잰 값이다. 기준 프레임 사진(`reference-*.png`)은 이 프로젝트에 넣지 않았다.

| 요소 | 값 |
|---|---|
| 캔버스 | 1080x1920, 바탕 `#000000`, 30000/1001 fps |
| KAIST 로고 | 로고(344x112 칸)를 x368 y106에 놓는다. 이 프로젝트에는 로고 파일이 없고, 사용자가 `재료/logo.png`로 둔다. 글자 y114-173 `#00549a`, 아래 곡선 y186-209 `#007cbe`-`#2c98d3` |
| 제목 1줄 | Gmarket Sans Bold, 흰색 `#FFFFFF`, 글자 높이 y329-418, 가운데 정렬, 최대 폭 x96-982 |
| 제목 2줄 | Gmarket Sans Bold, 청록 `#00D0E1`, 글자 높이 y437-526, 가운데 정렬 |
| 색 순서 | 영상마다 다르다. 솔직후기는 흰-청록, 카포전은 청록-흰. 강조할 줄이 청록이다 |
| 영상 화면 | y582-1337 (1080x756). 16:9 원본을 높이 756(폭 1344)으로 키우고 가운데를 1080으로 자른다 |
| 화면 안 자막 | 원본 편집본 자막을 화면 안 아래쪽에 둔다(작은 흰 글자, 화자 이름표) |
| 아래 안내 | Gmarket Sans Bold, 흰색, 글자 높이 y1392-1446, 가운데 정렬. 문구 `↓ 풀영상은 KAIST 채널` |
| 아래 여백 | y1447-1920은 비운다(YouTube 쇼츠 UI 자리) |
| 길이 | 45-60초 |
| 소리 | 원본 소리, 통합 음량 약 -19 LUFS, 피크 -3.4 dBTP (솔직후기 실측) |

글꼴 파일: `../assets/GmarketSansBold.otf` (이 프로젝트에 포함, 라이선스는 `../assets/GmarketSans-OFL.txt`). 크기는 렌더 결과를 기준 프레임과 같은 방법으로 재서 글자 높이가 위 값과 맞도록 정한다.

KAIST 로고는 상표이므로 이 프로젝트에 넣지 않았다. KAIST UI 안내 페이지(https://kaist.ac.kr/kr/html/kaist/010401.html)의 사용 조건을 따른다.
