# Approval message, spec.json and render

Read before sending the approval message (always) and before writing spec.json and rendering. (Routing and invariants live in `../SKILL.md`; this file is the detail.)

1. Send the user ONE approval message in exactly this order (plain Korean; items that do not apply are left out, the order never changes). Wait for a clear "좋아/OK" or edits. Do not render (and do not make a voice) before approval.

   If item 5 was sent, the user's answer decides step 4b of flow B. Nothing is searched, downloaded or voiced before this answer.
2. Write `spec.json` to `결과/<yymmdd>-<name>/spec.json` (schema in `spec-schema.md`). Use paths like `재료/<id>/video.mp4` (resolved from the project folder). Set `"output": "결과/<yymmdd>-<name>/shorts.mp4"`.
3. Render. **The final video is made ONLY by `render.ps1`. Never build, re-mux or fix the final file (picture or sound) with a direct `ffmpeg` command.** `render.ps1` checks the spec before it starts (see `visual-distribution.md`), normalizes the loudness to -19 LUFS, checks the result and writes `render-stamp.json` next to it; to re-check a finished video run the same command with `-Check` (it stops if the file was not made by `render.ps1`, was changed afterwards, differs from the spec's `output`, or is not normalized). If the render stops with a Korean message, fix `spec.json` and run it again; there is no option to skip a check.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .agents/skills/kaist-shorts-make/scripts/render.ps1 -Spec "결과/<yymmdd>-<name>/spec.json"
```

   The script prints each segment's start time on the output timeline, renders (about a minute or a few; tell the user it is working) and opens the mp4. Add `-NoOpen` to skip opening.
4. Report where `shorts.mp4` is, what it contains, and any warning the script printed (for example a title that was shrunk to fit). Finish with the review checklist from `AGENTS.md` (sources, faces, music/SFX/voice licenses, text approved). Never publish or upload.

If something fails, explain in one plain sentence and fix the spec (wrong path, in/out beyond the video length, missing file, missing logo). Do not install software; if FFmpeg, yt-dlp or Deno is missing, tell the user to run `setup-windows.bat` again.
