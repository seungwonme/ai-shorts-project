폰트 찾기

제목 글자가 있는 부분을 잘라 둔 사진입니다. 글꼴 이름은 사진만으로 확정할 수 없고, 아래 순서로 후보를 좁힙니다.

  1. 이 사진을 Codex 대화창에 붙여 넣고 이 제목 글꼴과 닮은 무료 글꼴 후보 5개를 알려줘라고 말합니다. 답은 후보일 뿐 정답이 아닙니다.
  2. 후보 이름을 눈누(noonnu.cc)에서 검색해 모양을 눈으로 비교하고, 글꼴 상세 페이지의 라이선스(상업 이용, 재배포)를 읽습니다.
  3. 글꼴 이미지 검색 서비스(예: 산돌구름 글꼴 찾기, WhatTheFont, WhatFontIs)에 이 사진을 올려 볼 수 있습니다. 영어 글꼴 위주인 서비스가 많고, 무료 범위와 로그인 여부는 직접 확인해야 합니다. 외부 사이트에 올리는 것이므로 공개된 영상의 화면만 올립니다.
  4. 가장 확실한 방법: 후보 글꼴로 같은 문구를 써서 원본 사진 위에 겹쳐 봅니다. Codex에게 후보 글꼴로 같은 문구를 그려서 원본과 비교해줘라고 부탁하세요.

무료로 쓸 수 있는 글꼴 예: Gmarket Sans(SIL 오픈 폰트 라이선스, 이 프로젝트에 들어 있음), Pretendard. 어떤 글꼴이든 쓰기 전에 라이선스 문서를 직접 읽으세요.

곡 찾기

영상 속 12초를 잘라 둔 소리 조각입니다. 배경 음악만 들리는 구간이 좋습니다.

{{music_note}}

  1. 유튜브 쇼츠라면 먼저 화면 아래의 소리 이름을 눌러 봅니다. 음원이 표시되는 영상이면 가장 빠릅니다.
  2. 곡 식별 서비스에 소리 조각을 올려 봅니다: AudD(audd.io), ACRCloud(acrcloud.com). 둘 다 계정이 필요하고 무료 범위가 정해져 있으며, 정책은 바뀔 수 있습니다. 외부에 올리는 것이므로 공개된 영상의 소리만 올립니다.
  3. 결과가 없다고 해서 무료 음원이라는 뜻은 아닙니다. 데이터에 없는 곡일 뿐입니다.
  4. 곡 이름을 알아내도 써도 된다는 허락은 아닙니다. 허락(라이선스)은 따로 확인합니다.

내 쇼츠에 쓸 음악, 효과음을 구하는 곳

  • 공유마당(gongu.copyright.or.kr): 곡마다 조건이 다릅니다. 공공누리 제1유형, CC BY처럼 상업 이용이 되는 것만 고르고, 출처 표시 조건을 지킵니다.
  • YouTube 오디오 라이브러리(YouTube Studio 안): 유튜브에 올릴 영상이면 저작권 클레임 위험이 낮은 편입니다. 다른 곳에 다시 쓸 때의 조건은 약관을 확인합니다.
  • Freesound(freesound.org): 효과음은 CC0 표시된 것만 씁니다.
  • 쓰지 않는 것: CC BY-NC(비영리 한정) 표시 음원. 게시하는 영상에는 쓰지 않습니다.

음악과 효과음 파일은 이 프로젝트 폴더나 저장소에 넣지 않고 재료 폴더에만 둡니다.
