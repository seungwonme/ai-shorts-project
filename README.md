# AI 쇼츠 프로젝트

AI(Codex)에게 말로 부탁해서 쇼츠 영상을 분석하고 만드는 연습용 프로젝트입니다. KAIST 행정 직원 대상 강의에서 쓰려고 만들었고, 개발을 몰라도 쓸 수 있습니다. 컴퓨터에는 Windows 11, ChatGPT 데스크톱 앱(Codex)이 필요합니다.

KAIST와 관계없는 연습용 도구입니다. KAIST 로고 파일은 들어 있지 않고, 사용하는 사람이 공식 안내 페이지에서 직접 받아 규정에 맞게 씁니다.

## 할 수 있는 것

- **쇼츠 분석**: 유튜브 쇼츠 주소를 주면 화면 틀, 시각 자료, 글자, 소리, 흐름(컷 길이와 순서)을 정리한 한 페이지 보고서를 만듭니다. 글꼴과 곡을 찾는 방법도 안내합니다.
- **쇼츠 만들기**: 유튜브 영상 주소나 뉴스 기사 주소를 주면 자료를 스스로 모아 1080x1920 세로 쇼츠를 만듭니다. 기사로 만들 때는 기사에 적힌 사실만으로 나레이션 대본을 쓰고, 사람이 승인한 뒤 Typecast 목소리를 입힙니다.

## 내려받기

1. 이 페이지 위쪽의 초록색 `Code` 버튼을 누르고 `Download ZIP`을 고릅니다. (git을 쓴다면 저장소 주소로 복제해도 됩니다.)
2. 받은 zip 파일을 마우스 오른쪽 버튼으로 눌러 "압축 풀기"를 합니다.
3. 압축을 푼 폴더 안의 [`시작하기.md`](시작하기.md)를 열어 순서대로 따라 합니다.

## 폴더 안내

| 이름 | 설명 |
|---|---|
| `시작하기.md` | 수업 전 준비(설치, 로고, Typecast 키)와 수업 중 하는 말 |
| `setup-windows.bat` | 필요한 프로그램(영상 도구)을 설치하는 파일 |
| `재료` | 처음에는 비어 있고, Codex가 주소에서 모은 영상, 글, 사진이 쌓입니다 |
| `결과` | Codex가 만든 보고서, 나레이션, 쇼츠 |
| `.agents` | Codex의 기능 두 가지(쇼츠 분석, 쇼츠 만들기)와 글꼴, 예시 설정 |
| `AGENTS.md` | Codex가 지킬 규칙 |

## 알아 둘 점

- 남의 영상, 사진, 음악은 쓸 권리가 있는 것만 쓰고 출처를 밝히세요. 올리기 전에 출처, 얼굴(초상권), 음악과 목소리 이용 조건, 글 내용을 사람이 확인하세요.
- Typecast 무료 플랜 목소리는 연습용입니다. 기관 채널에 올리려면 유료 플랜이 필요합니다. 자세한 내용은 `시작하기.md`에 있습니다.
- 글꼴 Gmarket Sans는 SIL 오픈 폰트 라이선스로 `.agents/skills/kaist-shorts-make/assets/`에 라이선스 파일과 함께 들어 있습니다.
- 이 프로젝트는 개인 API 키를 저장소에 두지 않습니다. 각자의 Typecast 키는 자기 컴퓨터 안에만 저장됩니다.
