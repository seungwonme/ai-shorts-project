# AI 쇼츠 프로젝트

AI(Codex)에게 말로 부탁해서 쇼츠 영상을 분석하고 만드는 연습용 프로젝트입니다. KAIST 행정 직원 대상 강의에서 쓰려고 만들었고, 개발을 몰라도 쓸 수 있습니다. 컴퓨터에는 Windows 10 또는 11, ChatGPT 데스크톱 앱(Codex)이 필요합니다. 실습 폴더는 Windows 11에서 확인했습니다.

KAIST와 관계없는 연습용 도구입니다. 영상에는 KAIST 로고가 기본으로 들어갑니다. 로고는 KAIST의 등록 상표이고, KAIST UI 안내 페이지(https://kaist.ac.kr/kr/html/kaist/010401.html)에 따르면 상업적 목적으로 쓸 수 없으며 교육과 행정 목적에 한해 제공됩니다.

## 할 수 있는 것

- **쇼츠 분석**: 유튜브 쇼츠 주소를 주면 영상의 여섯 가지 요소(화면 틀, 시각 요소, 글자, 말소리, 배경 음악, 효과음)와 컷과 편집점(분석에 쓰는 말)을 정리한 한 페이지 보고서를 만듭니다. 글꼴과 곡을 찾는 방법도 안내합니다.
- **쇼츠 만들기**: 유튜브 영상 주소나 뉴스 기사 주소를 주면 자료를 스스로 모아 1080x1920 세로 쇼츠를 만듭니다. 기사로 만들 때는 기사에 적힌 사실만으로 나레이션 대본을 쓰고, 사람이 승인한 뒤 Typecast 목소리를 입힙니다. 기사에 사진이 모자랄 때는 Openverse 검색으로 CC0(필요하면 CC BY) 사진 후보를 찾을 수도 있습니다(선택, 키 불필요, 라이선스와 초상권은 사람이 원본 페이지에서 확인). NC, ND, SA, 라이선스 없음, 로고와 캐릭터가 든 사진은 게시하는 영상에는 쓰지 않습니다.

## 내려받기

1. 이 페이지 위쪽의 초록색 `Code` 버튼을 누르고 `Download ZIP`을 고릅니다. (git을 쓴다면 저장소 주소로 복제해도 됩니다.)
2. 받은 zip 파일을 마우스 오른쪽 버튼으로 눌러 "압축 풀기"를 합니다.
3. 풀린 폴더 안의 `ai-shorts-project-main` 폴더에서 `setup-windows`를 더블클릭해 필요한 프로그램을 설치합니다.
4. 그다음은 강의 슬라이드 순서대로 따라 합니다. 막히면 Codex에게 "방금 뭐가 안 됐는지 쉽게 설명해줘"라고 물어보세요.

## 폴더 안내

| 이름 | 설명 |
|---|---|
| `setup-windows.bat` | 필요한 프로그램(영상 도구)을 설치하는 파일 |
| `키-입력.bat` | API 키(Typecast)를 메모장으로 붙여 넣는 파일. 따라 하실 분만 사용하고, 보기만 하면 필요 없습니다 |
| `env-template.txt` | `키-입력.bat`이 `.env`를 만들 때 쓰는 빈 양식 |
| `재료` | 효과음 4개(`sfx`)가 들어 있고, 배경 음악 17곡(`bgm`)도 zip에 이미 들어 있습니다. Codex가 주소에서 모은 영상, 글, 사진도 여기에 쌓입니다 |
| `결과` | Codex가 만든 보고서, 나레이션, 쇼츠 |
| `.agents` | Codex의 기능 두 가지(쇼츠 분석, 쇼츠 만들기)와 글꼴, 예시 설정 |
| `AGENTS.md` | Codex가 지킬 규칙 |

## 알아 둘 점

- 남의 영상, 사진, 음악은 쓸 권리가 있는 것만 쓰고 출처를 밝히세요. 올리기 전에 출처, 얼굴(초상권), 음악과 목소리 이용 조건, 글 내용을 사람이 확인하세요.
- Typecast 무료 플랜 목소리는 연습용입니다. 기관 채널에 올리려면 유료 플랜이 필요합니다. 어떤 요금제가 맞는지는 Typecast에 확인하세요.
- 글꼴 Gmarket Sans는 SIL 오픈 폰트 라이선스로 `.agents/skills/kaist-shorts-make/assets/`에 라이선스 파일과 함께 들어 있습니다.
- 이 프로젝트는 개인 API 키를 저장소에 두지 않습니다. 각자의 Typecast 키는 `키-입력.bat`으로 만든 `.env` 파일(자기 컴퓨터 안, 인터넷 저장소에 올라가지 않게 제외됨)에만 적습니다. 폴더를 zip으로 남에게 보낼 때는 `.env`를 빼세요.
