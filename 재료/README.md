# 재료 폴더

`bgm`(배경 음악 17곡)과 `sfx`(효과음 4개) 폴더에는 파일이 미리 들어 있습니다. 두 폴더 모두 GitHub zip에 들어 있어서 따로 받을 것이 없습니다. 나머지는 처음에는 비어 있습니다. Codex에게 주소를 알려 주면 필요한 영상, 글, 사진이 여기에 저절로 모입니다.

- 유튜브 영상: `이 영상으로 쇼츠 만들어 줘: 주소` 하면 `재료/영상번호/`에 영상, 정보, 대본(자막)이 모입니다.
- 뉴스 기사: `이 기사로 쇼츠 만들어 줘: 주소` 하면 `재료/기사-번호/`에 기사 글, 사진, 출처 기록이 모입니다.
- 내 파일을 직접 쓰고 싶으면 영상(mp4), 사진(png, jpg), 음성(wav, mp3)을 이 폴더에 넣으면 됩니다.
- Codex는 이 폴더의 파일을 읽기만 하고 바꾸지 않습니다.
- 남의 영상, 사진, 음악은 쓸 권리가 있는 것만 쓰세요. 완성본에는 출처를 적습니다.
- 이 폴더의 파일은 인터넷에 올라가지 않도록 git에서 제외되어 있습니다. 예외는 효과음 4개(`sfx`, CC0)와 그 기록 파일뿐입니다.
